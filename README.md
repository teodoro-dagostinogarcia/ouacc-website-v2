# OUACC website redesign

This folder is the static website for GitHub Pages. `index.html` is the site entry point.

The design uses Oxford blue, gold, green, rose and ivory, with Libre Baskerville for major headings and Inter for interface and body text.

The main navigation uses hover dropdowns on desktop and expandable menus on touch devices. Inner pages use a consistent right rail for section navigation on desktop. Long pages automatically include an on-page contents navigation.

The site is designed to work as a static GitHub Pages project site and uses relative links throughout.
