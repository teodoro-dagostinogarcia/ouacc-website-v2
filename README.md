# OUACC website draft

This repository contains the GitHub Pages preview of the Oxford University Association Croquet Club website.

The production site uses the existing public page paths wherever practicable. Legacy `.shtml` files are retained, and `index.html` mirrors are provided for directory URLs on GitHub Pages.

Public website files are in `public_html`.

Do not place private committee records, member lists, credentials, passwords, or working documents in this repository.

The original University-hosted site remains separate from this repository.
