OUACC website search

Search is implemented locally for GitHub Pages using search-index.json and search.html. The index is generated from the public HTML pages in this build. Relative URLs keep it compatible with the repository path https://teodoro-dagostinogarcia.github.io/ouacc-website-v2/ .
